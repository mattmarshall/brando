# The deployed deterministic tier, and nothing else.
#
# THIS FILE OWNS THE NAME `requirements.txt`, and the build's lock is
# `requirements-bazel.txt`, because only one of the two has a name that is
# load-bearing. Vercel's Python runtime resolves a manifest from a fixed
# filename list — `requirements.txt`, `pyproject.toml`, `Pipfile` — and reads
# nothing else, so a `requirements-service.txt` named in an `installCommand` was
# silently ignored and the BUILD lock was installed instead: 469 hashed pins
# dragging in grpcio-tools, lxml, pillow and python-pptx to serve five RPCs that
# emit SVG and JSON. Bazel's path, by contrast, is one explicit string in
# MODULE.bazel and moves for free.
#
# Vercel does not tree-shake Python: everything reachable is shipped. shapely
# pulls numpy, which is most of the ~110 MB; the whole bundle measures ~189 MiB
# against a 500 MB ceiling. Comfortable, but worth knowing which line costs what.
shapely
svgwrite
# The wire, and the servicers' status codes. `grpcio` is here for
# `grpc.StatusCode` rather than for a server: nothing binds a port in this
# deployment.
grpcio
protobuf
googleapis-common-protos
